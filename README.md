# Щоденна задача трьох тіл

Перший робочий варіант: створює GIF-анімацію ньютонівської задачі трьох тіл та, за наявності налаштувань, публікує її у Telegram-каналі.

## Запуск

1. Встановіть залежності: `pip install -r requirements.txt`.
2. Для локальної перевірки виконайте: `python main.py`.
3. Для публікації задайте змінні середовища `TELEGRAM_BOT_TOKEN` і `TELEGRAM_CHANNEL_ID`; бот повинен бути адміністратором каналу.

Після локального запуску поруч зі скриптом з'явиться `daily_three_body.gif`.

## Автоматичний запуск у Windows

Створіть у Планувальнику завдань щоденне завдання, яке запускає `python main.py` у папці цього проєкту. Воно працюватиме лише під час запуску, а потім завершиться.
